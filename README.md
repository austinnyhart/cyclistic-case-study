# cyclistic-case-study
Analytical case study on rider behavior patterns to better inform marketing campaigns designed at converting customers to members. This is my first case study using a large data set, performed as a capstone on the google data analytics certification course. 
The full typed up report will be uploaded in this repository, as well as the data sets I utilized and the full year aggregated data. 
The full data set is far too large to upload to this repository, but the data files are available here: https://divvy-tripdata.s3.amazonaws.com/index.html
